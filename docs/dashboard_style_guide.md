# PulseIQ Dashboard Style Guide

## Dashboard
Headcount & Departments

## Purpose
Help HR and leadership understand workforce size, department distribution, tenure, role mix, and workforce changes.

## Layout
- Header: dashboard name and reporting period.
- First row: current headcount, department count, joiners, and leavers.
- Second row: monthly headcount trend and department distribution.
- Third row: tenure bands and role mix.
- Fourth row: joiners versus leavers over time.
- Filters: department and date range.

## Visual standards
- Use a consistent, colour-blind-conscious palette.
- Use readable labels and avoid unnecessary decoration.
- Use line charts for trends, bar charts for comparisons, and a donut chart only for a small number of categories.
- Use consistent date formats and number formats.
- Give every chart a descriptive title and a one-line takeaway.
- Show the reporting period and metric definition where needed.
- Never display invented values as actual business results.

## Review checklist
- Put the most important KPI first.
- Check readability on laptop-sized screens.
- Use labels as well as colour to communicate differences.
- Confirm that filters affect the intended charts.
- Reconcile displayed values with warehouse SQL results.
- Document any limitations or missing data.

## Design review
The initial layout is a proposed design. Review it after implementation and record any changes before treating the dashboard as complete.
